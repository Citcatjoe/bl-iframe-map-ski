Densité : anti-surcharge

Implémenté dans le proto. Avec ~270 domaines, les pastilles ne peuvent pas toutes s'afficher : la carte décide lesquelles montrer.

  • Deux couches : un point rouge pour chaque domaine (toujours visible) + une pastille « météo · °C » par-dessus.
  • Collision native : une pastille qui en chevaucherait une autre est masquée ; son point reste.
  • Priorité : sélection > survol > neige fraîche prévue sur 3 jours. Les domaines les plus enneigés gagnent la place.
  • Niveau de détail : au zoom régional (≥ 8,6), la pastille affiche aussi le nom.
  • 632 / mobile : points seuls à l'échelle Suisse, pastilles dès le zoom 7,8 ; un indice « Zoome pour voir les températures » guide le lecteur.
  • Rendu en couches WebGL (plus en éléments HTML) : fluide même avec 300 domaines, et identique sous Mapbox GL.

API — à régler après l'UI

  • MapLibre GL (rendu) : open source BSD, aucune limite.
  • OpenStreetMap / OpenFreeMap (fond) : données ODbL, attribution obligatoire ; service gratuit mais bénévole, sans SLA → auto-héberger (PMTiles) pour le trafic Blick.
  • Relief AWS Terrarium : dataset public gratuit, sans SLA.
  • Open-Meteo : code AGPLv3, données CC BY 4.0 ; API gratuite en non-commercial ≤ 10 000 appels/jour → abonnement pour Blick, ou auto-hébergement illimité.
  • MétéoSuisse OGD : gratuit, sans restriction, source à citer ; formats bruts (GRIB/STAC) → backend requis.
  • Mapbox : propriétaire, quota gratuit puis facturation au chargement de carte (grille à vérifier).
  • Dans tous les cas : cron horaire → weather.json en cache ; ~24 appels/jour au lieu d'un par lecteur.

Choix d'ergonomie

  • 964 : panneau fixe 312 px + carte ; survol = infobulle, clic = fiche.
  • 632 : carte pleine largeur, bouton « Liste · 16 » qui ouvre un tiroir superposé.
  • Mobile : bottom sheet ; toucher la recherche déplie la liste, choisir un domaine ouvre la fiche.
  • Survol d'une ligne de liste → le marqueur se met en évidence sur la carte.
  • Filtre canton en chips (Tag Blick), tri Neige 3 j / A–Z.
  • Zones tactiles ≥ 36 px, input 16 px (pas de zoom iOS).

Données & API

  • Météo : Open-Meteo (modèle MeteoSwiss ICON-CH, 1–2 km, sans clé, CC BY 4.0). Gratuit en non-commercial seulement → abonnement pour Blick, ou MeteoSwiss OGD direct (gratuit, mais GRIB/STAC → nécessite un backend).
  • Architecture : cron horaire → weather.json en cache, séparé du resorts.json statique (comme prévu).
  • Mapbox : style Studio aux couleurs Blick (gris chauds, relief ombré, labels réduits), cooperativeGestures, init au scroll (IntersectionObserver) car facturé par chargement.

Hypothèses du prototype

  • Fond de carte : MapLibre + OpenFreeMap (API compatible Mapbox GL) faute de token ; en prod, on remplace l'URL du style et on ajoute le token.
  • 16 domaines d'exemple, coordonnées approximatives, liens non vérifiés — à remplacer par le JSON validé.
  • Météo réelle (appel live), au niveau du village, pas du sommet.
  • Interface en français, tutoiement Blick.
